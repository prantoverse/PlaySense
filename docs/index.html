Watch how people actually play your game.

PlaySense is a free Unity package for playtesting. It records where testers go, what they look at and what they do, then shows it as heatmaps, replays and plain-language reports, for one player or all of them.

Unity Package Manager → Add package from git URL
https://github.com/prantoverse/PlaySense.git?path=/Packages/com.prantoverse.playsense
Source on GitHub Documentation Unity 6 or newer. Free, MIT licensed.

Four things it records, all on one clock

Each one is a separate module. Use what you need and delete the rest: its components, dashboard tab and replay layer go with it.

Movement

Paths, speed and idle time for the player, teammates, enemies or a ball. Time-spent heatmaps in the Scene view.

Add PlaySenseAgent to anything that moves.

Attention

What the player looked at, for how long, and whether they came back to it. Uses the real camera frustum and line of sight.

Mark objects with PlaySenseTarget.

Events

Kills, deaths, pickups, puzzle solves, menu choices: anything you log, with your own key/value details.

One line: PlaySenseEvents.Log(…)

Performance

Frame rate, 1% lows and hitches per scene, so you can tell a confusing room from a slow one.

Add the Performance module to the manager.

Answer questions about all your players at once

Every playthrough is one session file. The All Sessions view adds them up, so a pile of playtests turns into answers.

  • How many players used the ability? Share of sessions with at least one event.
  • How did they get their kills? Breakdowns by any detail you logged.
  • How far did they get? Share of sessions that reached each level.
  • Did anyone notice the clue? Share of players who looked at each object.

Works for whatever you're making

Nothing is tied to a genre. You decide which moments matter and log them; PlaySense does the counting.

Record anything else with your own module

        

          Subclass PlaySenseModule, sample whatever you like, and save it into the session. Add a Dashboard tab or a
          Replay layer the same way; PlaySense finds them on its own.
        

        

          
            
OnSessionStartRecording starts

            
OnSessionUpdateEvery frame, on the session clock

            
OnSceneChangedThe player loads a new level

            
OnSessionStopRecording stops: save your data

          
        

      


public class HealthModule : PlaySenseModule
{
    public PlayerHealth player;
    HealthData data;

    public override void OnSessionStart(PlaySenseSession s)
        => data = new HealthData();

    public override void OnSessionUpdate(PlaySenseSession s, float dt)
    {
        data.Times.Add(s.Time);
        data.Health.Add(player.Current);
    }

    public override void OnSessionStop(PlaySenseSession s)
        => s.SetModuleData(ModuleId, data);
}

    

  


  

    

      
Your playtest data stays with you

      

        

          
No servers, no accounts

          
Sessions are plain JSON files on your disk. Nothing is sent anywhere unless you choose to upload it.

        

        

          
Safe to ship

          
PlaySenseEvents.Log does nothing when PlaySense isn't recording, so the calls can stay in your build.

        

        

          
Free and open source

          
MIT licensed. Read it, change it, use it in commercial games.
