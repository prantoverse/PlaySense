# PlaySense

Lightweight playtesting toolkit for Unity: records player movement, visual attention and gameplay events, then shows them in a Dashboard, a Scene-view Replay with heatmaps, and PDF reports.

Quick start: select your player, run **Window → PlaySense → Set Up Scene**, mark objects with **GameObject → PlaySense → Mark as Attention Target**, press Play.

Full documentation: https://github.com/prantoverse/playsense
